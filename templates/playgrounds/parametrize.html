Форма регистрации проверяет пароль по правилам — по порядку, показывая первую найденную ошибку:

  1. длина меньше 8 → «Минимум 8 символов»;
  2. есть пробел → «Пароль не должен содержать пробелы»;
  3. нет цифры → «Нужна хотя бы одна цифра»;
  4. нет заглавной буквы → «Нужна заглавная буква»;
  5. нет спецсимвола (!@#$%^&*) → «Нужен спецсимвол»;
  6. иначе → «Аккаунт создан».

Напиши один тест с @pytest.mark.parametrize на 6 случаев: для каждого правила — пароль, который нарушает именно его, плюс один валидный. Каждый случай проверяет точный текст сообщения.

Миссия засчитывается, когда покрыты все 6 исходов (сервер собирает их из разных запусков страницы).
