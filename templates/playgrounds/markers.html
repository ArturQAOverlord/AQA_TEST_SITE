Страница статуса сервисов — идеальный кандидат в smoke-тесты: быстрые проверки, которые запускают первыми (после деплоя, перед полным прогоном).

  1. Напиши тест: нажми «Проверить», убедись, что все три сервиса в статусе «OK».
  2. Пометь тест маркером @pytest.mark.smoke (маркер уже зарегистрирован в pytest.ini).
  3. Запусти только smoke-тесты: pytest exercises -m smoke.

Проверка задания разбирает код: у test_markers должен быть маркер smoke.

{% endblock %} {% block hint %} 
import pytest

@pytest.mark.smoke
def test_markers(page: Page):
    ...

Полезные выражения для -m: "smoke and not slow", "not slow". Незарегистрированный маркер вызывает предупреждение, а с --strict-markers — ошибку. Родственники маркеров: @pytest.mark.skip(reason=…), skipif(условие, reason=…), xfail — «ожидаемо падает, баг уже заведён».
