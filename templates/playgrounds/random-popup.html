Для «непредсказуемых» оверлеев в Playwright есть add_locator_handler: перед каждым действием Playwright проверяет, не появился ли указанный элемент, и если да — вызывает твой обработчик.

page.add_locator_handler(
    page.get_by_role("dialog", name="Специальное предложение"),
    lambda: page.get_by_role("button", name="Не сейчас").click(),
)

Только не пытайся проверять баннер через if banner.is_visible() — он может появиться через миллисекунду после проверки.
