Тот же виджет котировок, но тикер LAB ещё не запущен на бирже: настоящий сервер отвечает {"error": "unknown symbol"}. А проверить отображение нужно уже сейчас.

Притворись WebSocket-сервером: когда страница пришлёт {"subscribe": "LAB"}, ответь двумя фреймами — {"symbol": "LAB", "price": 1000} и {"symbol": "LAB", "price": 1100}. Проверь, что виджет показывает «LAB: 1100 ₽ (+10.0%)».

def fake_server(ws: WebSocketRoute):
    def on_message(message):
        if json.loads(message).get("subscribe") == "LAB":
            ws.send(json.dumps({"symbol": "LAB", "price": 1000}))
            ...
    ws.on_message(on_message)

page.route_web_socket("**/ws/quotes", fake_server)
page.goto(...)

Без ws.connect_to_server() настоящий сервер вообще не участвует. С ним можно пропускать часть сообщений к серверу и подменять только нужные.
