Корпоративный поиск жёстко настроен: поле заблокировано со значением selenium, и кнопка «Найти» отправляет GET /api/search?q=selenium.

Не трогая поле, сделай так, чтобы на сервер ушёл запрос с q=playwright, и проверь, что в результатах ровно один пункт — «Playwright».

Подделать ответ через fulfill не выйдет: страница сверяет результат с заголовком ответа X-Lab-Query, который ставит настоящий сервер.

def swap_query(route):
    url = route.request.url.replace("q=selenium", "q=playwright")
    route.continue_(url=url)

page.route("**/api/search*", swap_query)

continue_() умеет менять url, method, headers и post_data. Менять можно только адрес на том же протоколе — подменить запрос на совсем другой хост так нельзя.
