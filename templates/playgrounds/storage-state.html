Логиниться через форму в каждом тесте — медленно. Обычный приём: войти один раз, сохранить состояние браузера (cookies + localStorage) в файл и переиспользовать его в других тестах.

  1. Открой страницу и войди: student / playwright123. Сессия хранится в httpOnly-cookie.
  2. Сохрани состояние контекста в файл: page.context.storage_state(path=...).
  3. Создай новый контекст из этого файла, открой в нём страницу — должен сразу открыться кабинет без формы входа.
  4. В новом контексте нажми «Мои курсы».

Засчитывается, только если кабинет открылся сразу, без входа на этой вкладке.

def test_storage_state(page: Page, browser: Browser, base_url: str, tmp_path):
    ...  # вход через форму
    state = tmp_path / "state.json"
    page.context.storage_state(path=state)

    context = browser.new_context(storage_state=state, base_url=base_url)
    new_page = context.new_page()
    ...
    context.close()

В реальных проектах вход выносят в session-фикстуру, а browser_context_args подкладывает storage_state во все тесты.
