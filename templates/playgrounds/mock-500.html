Список команды загружается кнопкой «Загрузить пользователей» (GET /api/users). Настоящий сервер никогда не падает, а нам нужно проверить экран ошибки.

  1. Замокай ответ /api/users со статусом 500.
  2. Нажми «Загрузить пользователей» и проверь сообщение «Сервер недоступен (500)».
  3. Сними мок и нажми «Повторить» — должны загрузиться 3 настоящих пользователя.
{% endblock %} {% block hint %} 
page.route("**/api/users", lambda route: route.fulfill(status=500, body="Internal Server Error"))
...
page.unroute("**/api/users")

unroute снимает обработчики для этого шаблона, и запросы снова идут на настоящий сервер.
