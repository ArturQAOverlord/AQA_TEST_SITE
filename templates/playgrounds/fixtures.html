Личный кабинет студента доступен только после входа. Логиниться через форму в каждом тесте — долго и не по делу: тест про курсы не должен падать из-за формы входа.

  1. Напиши фикстуру logged_in_page, которая входит через API (POST /api/login с {"username": "student", "password": "playwright123"}) и возвращает page.
  2. Тест test_fixtures принимает эту фикстуру, открывает кабинет и нажимает «Продолжить обучение».

Вход через форму на странице засчитывается как провал. Проверка задания разбирает код: тест должен принимать собственную фикстуру, а она — ходить в /api/login.

{% endblock %} {% block hint %} 
@pytest.fixture
def logged_in_page(page: Page) -> Page:
    response = page.request.post("/api/login", data={...})
    expect(response).to_be_ok()
    return page

page.request делит cookies с браузерным контекстом — сессия из ответа сразу действует и для страницы. Если фикстура нужна многим файлам, перенеси её в exercises/conftest.py. Для очистки после теста используют yield вместо return.
