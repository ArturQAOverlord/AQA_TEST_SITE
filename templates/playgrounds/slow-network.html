Поиск по инструментам (GET /api/search?q=...) отвечает почти мгновенно, поэтому индикатор «Ищем…» на локальном сервере никто не успевает увидеть.

Задержи ответ минимум на 1,5 секунды, найди py и проверь, что сначала виден индикатор «Ищем…», а потом — результаты, среди которых есть «pytest».

{% endblock %} {% block hint %}

Самый надёжный способ в sync API — «придержать» запрос: обработчик только запоминает route, а тест сам решает, когда его отпустить.

held = []
page.route("**/api/search*", lambda route: held.append(route))
... # клик по «Найти»
expect(page.get_by_text("Ищем…")).to_be_visible()
page.wait_for_timeout(1500)
held[0].continue_()

time.sleep() внутри обработчика блокирует весь Playwright — проверки в это время тоже стоят. Для Chromium есть ещё эмуляция медленной сети через CDP (Network.emulateNetworkConditions).
