Панель настроек собрана из веб-компонентов, вложенных друг в друга: <app-shell> → <settings-panel> → <toggle-row>, у каждого свой open shadow root.

Включи переключатель «Push-уведомления» (и только его) и проверь, что у него aria-checked="true".

{% endblock %} {% block hint %}

Сколько бы уровней Shadow DOM ни было, role- и CSS-локаторы проходят их насквозь: page.get_by_role("switch", name="Push-уведомления"). Рядом есть «Push-уведомления по ночам» — не забудь про exact=True.

В DevTools попробуй document.querySelector('toggle-row') — получишь null. Обычный DOM API в shadow root не заглядывает, а Playwright — да.
