Не всё надо делать через интерфейс. У page есть встроенный HTTP-клиент page.request, который делит cookies с браузером.

  1. GET /api/users: статус 200, в ответе ровно 3 пользователя, первый — «Алиса».
  2. POST /api/todos с телом {"title": "Написать тест"}: статус 201, в ответе title совпадает, done — false, id — целое число.
  3. Открой /play/api-assertions и проверь, что созданная задача видна в списке с пометкой «создана тобой».

Страница опознаёт «твою» задачу по cookie, которую сервер ставит в ответ на POST, поэтому задачу нужно создать именно через page.request, а не сторонним клиентом.

{% endblock %} {% block hint %} 
response = page.request.post("/api/todos", data={"title": "Написать тест"})
expect(response).to_be_ok()          # 2xx
assert response.status == 201
todo = response.json()

Относительные URL работают, потому что у контекста есть base_url. expect(response).to_be_ok() проверяет только диапазон 2xx — точный код проверяй отдельно.
