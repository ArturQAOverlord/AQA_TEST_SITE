Отправь в архив заказ #A-1042 — нажми его «кнопку» с data-action="archive".

Попрактикуйся и в CSS, и в XPath: решение одной строкой можно написать на любом из них.

Ловушка: есть ещё заказ #A-10421, поэтому filter(has_text="#A-1042") найдёт две строки. Нужно точное совпадение текста.

CSS + фильтр Playwright:

row = page.locator("div.order-row").filter(has=page.get_by_text("#A-1042", exact=True))
row.locator("[data-action=archive]").click()

Чистый XPath — от текста вверх к строке и вниз к кнопке:

//span[text()='#A-1042']/ancestor::div[contains(@class,'order-row')]//div[@data-action='archive']
