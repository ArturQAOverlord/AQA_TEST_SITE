Справочник на 10 000 пользователей. Чтобы страница не тормозила, список виртуализирован: в DOM живут только строки, которые сейчас видны (плюс небольшой запас). Все строки одинаковой высоты — 32 px.

Найди пользователя, указанного над списком (номер случайный), и нажми «Открыть» в его строке.

click() сам прокручивает к элементу, только если элемент уже есть в DOM. Здесь его нет, пока не доскроллишь.

{% endblock %} {% block hint %}

Раз высота строк известна, можно сразу прыгнуть к нужному месту:

users = page.get_by_role("list", name="Пользователи")
users.evaluate("(el, top) => el.scrollTop = top", (number - 1) * 32)

Если высоты неизвестны — крути колесом над списком (users.hover(), затем page.mouse.wheel(0, 3000)), пока строка не появится. И не забудь про exact=True: «Пользователь #734» — подстрока «Пользователь #7342».
