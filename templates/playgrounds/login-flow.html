Полный сценарий авторизации. Учётка: admin / secret.

  1. Нажми «Войти» с пустыми полями — проверь ошибку «Введите логин».
  2. Введи admin и неверный пароль — проверь ошибку «Неверный логин или пароль».
  3. Войди с правильным паролем — проверь заголовок «Добро пожаловать, admin!».
  4. Нажми «Выйти» — проверь, что снова видна форма входа, а поле пароля пустое.

Сервер «думает» над логином около секунды.

Сценарий длинный — удобно вынести вход в функцию-хелпер:

def login(page, username, password):
    page.get_by_label("Логин").fill(username)
    page.get_by_label("Пароль").fill(password)
    page.get_by_role("button", name="Войти").click()

В настоящих проектах такие хелперы превращаются в Page Object.

Ловушка: get_by_role("heading", name="Добро пожаловать, admin!") найдёт и «Добро пожаловать, Admin!» — без exact=True имя сравнивается без учёта регистра. Для проверки текста надёжнее expect(...).to_have_text(...): строковое сравнение там регистрозависимое.
