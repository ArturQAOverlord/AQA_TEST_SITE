Справочник контактов. Выполни все операции и сохрани результат:

  1. Создай контакт: «Добавить» → имя Глеб, телефон +7 999 000-00-04 → «Сохранить».
  2. Измени телефон Бориса на +7 999 111-11-11 (кнопка «Изменить» в его строке).
  3. Удали Веру: «Удалить» в её строке и подтверди нативный confirm().
  4. Проверь таблицу: остались ровно Алиса, Борис и Глеб (в таком порядке), у Бориса новый телефон.
  5. Нажми «Сохранить изменения».

Удобно завести хелпер «строка по имени»:

def row(name):
    return page.get_by_role("row").filter(has=page.get_by_role("cell", name=name, exact=True))

Форма открывается в диалоге — ищи поля внутри page.get_by_role("dialog"). Для удаления подпишись на dialog до клика. Итог удобно проверить одним expect(page.get_by_test_id("contact-name")).to_have_text([...]).
