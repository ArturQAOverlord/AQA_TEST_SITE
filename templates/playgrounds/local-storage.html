При каждом открытии страницы показывается онбординг из пяти слайдов, который перекрывает интерфейс. Он не показывается, если в localStorage есть onboarding_done = "true".

В тестах пролистывать онбординг каждый раз — долго. Запиши флаг в localStorage, перезагрузи страницу и нажми «Создать проект». Засчитывается, только если онбординг на этой загрузке страницы не появлялся вовсе.

{% endblock %} {% block hint %}

localStorage привязан к origin, поэтому сначала нужно открыть страницу сайта:

page.goto("/play/local-storage")
page.evaluate("localStorage.setItem('onboarding_done', 'true')")
page.reload()

Как обойтись без лишней загрузки — смотри миссию про add_init_script.
