Две формы загрузки:

  1. Аватар. Настоящий <input type="file"> скрыт, видна только красивая кнопка. Загрузи в него любой файл .png.
  2. Отчёт. Кнопка «Прикрепить отчёт» открывает системное окно выбора файла. Загрузи файл с именем report.csv.

Файлы не обязательно должны существовать на диске.

{% endblock %} {% block hint %}

Скрытому input можно передать файл напрямую, даже из памяти:

page.get_by_label("Аватар").set_input_files(
    files=[{"name": "me.png", "mimeType": "image/png", "buffer": b"fake"}]
)

Системное окно перехватывают так:

with page.expect_file_chooser() as fc_info:
    page.get_by_role("button", name="Прикрепить отчёт").click()
fc_info.value.set_files(...)
