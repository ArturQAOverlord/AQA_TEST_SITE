Панель проекта вызывает нативные диалоги браузера. Сделай по порядку:

  1. «Удалить черновики» показывает confirm() — подтверди.
  2. «Удалить проект» тоже показывает confirm() — откажись.
  3. «Переименовать» показывает prompt() — введи Lab 2.0.
{% endblock %} {% block hint %}

По умолчанию Playwright автоматически отклоняет все диалоги. Чтобы ответить по-своему, подпишись на событие до клика:

page.once("dialog", lambda dialog: dialog.accept())
page.get_by_role("button", name="Удалить черновики").click()

page.once("dialog", lambda dialog: dialog.accept("Lab 2.0"))

page.once срабатывает один раз, page.on — на все диалоги. У dialog есть .message и .type — их удобно проверять.
