Страница читает фича-флаги из window.__LAB_FLAGS__ в момент загрузки, ещё до того, как тест успеет что-либо сделать через evaluate.

Включи флаг newCheckout: true, открой страницу и нажми «Новое оформление заказа». Кроме того, страница показывает «счастливое число» из Math.random() — сделай так, чтобы оно было ровно 42 (подмени Math.random, чтобы он всегда возвращал 0.42).

{% endblock %} {% block hint %}

add_init_script выполняет код в каждом новом документе до скриптов страницы:

page.add_init_script("""
    window.__LAB_FLAGS__ = { newCheckout: true };
    Math.random = () => 0.42;
""")
page.goto("/play/init-script")

Так же в тестах «замораживают» случайность, отключают анимации и подсовывают заглушки сторонних SDK.
