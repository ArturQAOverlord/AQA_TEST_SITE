Мессенджер, которым удобно пользоваться с клавиатуры. Выполни три шага:

  1. Отправь сообщение Привет клавишей Enter (кнопки отправки нет).
  2. Открой «Настройки» и закрой окно клавишей Escape (кнопки закрытия тоже нет).
  3. Открой палитру команд сочетанием Control+K.
{% endblock %} {% block hint %}

locator.press("Enter") нажимает клавишу на конкретном элементе, page.keyboard.press("Escape") — там, где сейчас фокус. Сочетания пишутся через плюс: "Control+K". На macOS для кроссплатформенности есть "ControlOrMeta+K".
