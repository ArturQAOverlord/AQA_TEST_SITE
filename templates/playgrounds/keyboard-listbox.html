Кастомный выпадающий список «Основной язык» сделан по паттерну ARIA combobox и управляется только с клавиатуры: клик мышью по пункту засчитывается как ошибка.

  • Фокус на поле + ArrowDown или Enter — открыть список;
  • ArrowDown / ArrowUp — двигать подсветку;
  • Enter — выбрать подсвеченный пункт.

Выбери Python. Порядок пунктов случайный.

{% endblock %} {% block hint %}

Подсвеченный пункт хранится в aria-activedescendant у combobox и в aria-selected="true" у пункта. Жми стрелку, пока подсвеченным не станет нужный:

combo = page.get_by_role("combobox", name="Основной язык")
combo.focus()
combo.press("ArrowDown")
for _ in range(10):
    if page.get_by_role("option", name="Python", selected=True).count():
        break
    combo.press("ArrowDown")
combo.press("Enter")
