Когда тестов становится много, на первый план выходит поддерживаемость:

  • Page Object — класс на страницу: локаторы и действия в одном месте, тест описывает сценарий. Поменялась вёрстка — правится один класс, а не сто тестов.
  • Фикстуры готовят окружение: вход через API вместо формы, тестовые данные, очистка после теста (yield). Общие фикстуры живут в conftest.py.
  • Маркеры (@pytest.mark.smoke) делят тесты на группы: pytest -m smoke. Маркеры регистрируются в pytest.ini.
  • Независимость. Тест создаёт свои данные (с уникальными именами), не рассчитывает на чужие и не зависит от порядка запуска. Только такие тесты можно гонять параллельно: pytest -n 4.
