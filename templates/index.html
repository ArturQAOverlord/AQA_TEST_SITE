Как пользоваться

  1. Запусти сайт: python app.py — он будет доступен на http://127.0.0.1:5000.
  2. Открой миссию, прочитай задание и потыкай песочницу руками — она открывается по адресу /play/<миссия>.
  3. Напиши тест прямо на странице миссии — в редакторе уже лежит стартовый шаблон — и нажми «▶ Запустить» (или Ctrl+Enter). Под редактором появится вывод pytest. Когда тест доводит миссию до конца, песочница показывает data-status="success", а миссия здесь становится зелёной.
  4. Или в своей IDE: редактор сохраняет код в exercises/web/test_<миссия>.py — этот файл можно открыть в VS Code / PyCharm и запускать pytest exercises --headed.
  5. Проверь тест глубже: у миссий с пометками 🧬 🔍 🛠 📐 нажми «Запустить проверку» на странице миссии (или python verify.py <миссия>) — тест прогонится на других версиях страницы.
  6. Застрял — открой подсказку. Совсем застрял — эталонное решение (его же можно запустить: pytest tests).
Что считается провалом попытки
  • Любое неверное действие (не тот элемент, не те данные) — провал окончательный: чтобы попробовать снова, нужна новая загрузка страницы. Тест, который «кликает всё подряд», миссию не пройдёт.
  • Синтетические события: dispatch_event("click"), el.click() через evaluate. Песочница принимает только настоящие клики и нажатия клавиш Playwright.
  • Подмена статуса миссии через evaluate.
  • Обход сценария: прямой переход на страницу результата, клик через force=True по движущемуся или перекрытому элементу и т.п.
